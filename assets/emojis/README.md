# 表情包目录

把表情包图片（.png / .jpg / .jpeg / .gif / .webp）放进这个目录即可。

肥鱼随机冒泡时会从这里随机挑一张发到群里（emoji_ratio 概率）。

## 用法
1. 把喜欢的表情包图片文件复制到这里（文件名随意，中文英文都行）；
2. 重启 main.py（或等下一次随机冒泡）；
3. 肥鱼就会随机发这些表情包了。

## 提示
- 建议用「大肥鱼 / 鲸鱼娘」风格的表情包更贴人设；
- 图片别太大（建议 < 1MB，太大的图发送会慢）；
- 不需要表情包功能时，把 config.yaml 里 random.emoji_ratio 设为 0 即可。
